Deckhand setup media lives here.

Use one folder per MCP host from `deckhand.connect_hosts.setup_asset_manifest()`.
Preferred filenames are:

- `step-1.webp`
- `step-2.webp`
- `walkthrough.mp4`

Keep files small enough for AnkiWeb distribution, and prefer WebP screenshots
before video unless motion is essential to the install step.
