# Domain quality lenses

Use these lenses when generic card advice is not enough. They are not scripts; they help you preserve quality while still honoring the user's intent. The rubric still applies on top.

## Escape hatches

- If the user asks for speed, breadth, or rough cards, you may produce a clearly labeled draft preview and offer a polish pass.
- If source material exists, cite it. If a claim is not supported by the source, label it `source-needed` instead of making it sound authoritative.
- For low-risk practice material, model-generated drafts without source material are allowed when labeled honestly.
- For source-sensitive or authority-sensitive material, the safety floor is higher: no unsourced authoritative claims and no invented citations. This includes medical, legal, exam-specific, clinical, regulatory, and user-supplied course material.

## Medical and health-science

Strict grounding, no exceptions:

- Create or edit medical cards **only** from provided, cited, or Deckhand-accessible source material. An uncited medical card is a rubric **blocker**.
- Never present model memory as medical authority. Flag uncertainty, outdated material, conflicting sources, and missing clinical context out loud.
- Educational language, not diagnosis or treatment advice.
- Split cards that mix pathophysiology, diagnosis, management, contraindications, criteria, and exceptions — each is its own retrieval target.
- If the user asks for medical cards without a source, help by drafting a scaffold, search/source checklist, or `source-needed` preview. Do not write authoritative medical facts as if grounded.

Patterns that work: mechanism, discriminator (X vs Y), indication, contraindication, criteria, anatomy, lesion → effect, pharmacology, organism, pathology, image-based identification.

## Language learning

Infer or establish: target language, learner level, native language, and which *direction* the learner needs —

- **Recognition**: target language → meaning.
- **Production**: native language, image, or context → target language.
- **Listening**: audio → meaning, transcription, or form.

Patterns that work: sentence mining (one target item in a natural sentence), cloze grammar (one missing form in context), minimal pairs (contrast sound, spelling, grammar, or meaning), usage notes (register, politeness, dialect, collocation).

Prefer real examples and learner-useful context over isolated dictionary entries. If the user asks for a count ("50 Japanese cards") and gives no source, infer a reasonable beginner/default pattern, preview a first batch, label it model-generated practice material, and offer to continue. Mark uncertain translations or usage notes as uncertain instead of pretending nuance is settled — confident wrong nuance is a rubric blocker (invented-authority).

## Slides and lectures

Preserve the instructor's structure while improving the cards:

- Keep lecture title, section, slide title, and slide number; cite slide number/title on every card.
- Turn slide bullets into learning targets — a screenshot with a question mark is a prompt-dump, not a card.
- Use images when the visual relationship *is* the target: anatomy, pathways, diagrams, charts, maps, workflows.
- Split dense slides into multiple cards; optionally add one section-overview card per major section.
