# Domain rules

Hard rules and proven patterns for the three domains where generic card advice fails. Read the section that matches the material; the rubric still applies on top.

## Medical and health-science

Strict grounding, no exceptions:

- Create or edit medical cards **only** from provided, cited, or Deckhand-accessible source material. An uncited medical card is a rubric **blocker**.
- Never present model memory as medical authority. Flag uncertainty, outdated material, conflicting sources, and missing clinical context out loud.
- Educational language, not diagnosis or treatment advice.
- Split cards that mix pathophysiology, diagnosis, management, contraindications, criteria, and exceptions — each is its own retrieval target.

Patterns that work: mechanism, discriminator (X vs Y), indication, contraindication, criteria, anatomy, lesion → effect, pharmacology, organism, pathology, image-based identification.

## Language learning

First establish: target language, learner level, native language, and which *direction* the learner needs —

- **Recognition**: target language → meaning.
- **Production**: native language, image, or context → target language.
- **Listening**: audio → meaning, transcription, or form.

Patterns that work: sentence mining (one target item in a natural sentence), cloze grammar (one missing form in context), minimal pairs (contrast sound, spelling, grammar, or meaning), usage notes (register, politeness, dialect, collocation).

Prefer real examples and learner-useful context over isolated dictionary entries. Mark uncertain translations or usage notes as uncertain instead of pretending nuance is settled — confident wrong nuance is a rubric blocker (invented-authority).

## Slides and lectures

Preserve the instructor's structure while improving the cards:

- Keep lecture title, section, slide title, and slide number; cite slide number/title on every card.
- Turn slide bullets into learning targets — a screenshot with a question mark is a prompt-dump, not a card.
- Use images when the visual relationship *is* the target: anatomy, pathways, diagrams, charts, maps, workflows.
- Split dense slides into multiple cards; optionally add one section-overview card per major section.
